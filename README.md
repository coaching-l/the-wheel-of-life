# 人生の輪（COACHING-L）

コーチング事業「COACHING-L」の研修で、参加者が自分のスマホで使う「人生の輪」のワークシートです。
ブログ（WordPress）の「人生の輪」ツールと同じ8つの領域・色・輪のグラフを使い、研修のワークに合わせた機能を加えています。

- HTML・CSS・JavaScript だけで動きます（ビルド不要、外部ライブラリなし）
- **入力した内容は、参加者の端末（ブラウザ）の中にだけ保存されます。** 送信機能、アクセス解析、Cookie は一切使っていません
- スマホ優先のレイアウトで、PC・タブレットでも使えます（iPhone の Safari、Chrome、Edge に対応）
- 端末の表示設定（ライト／ダーク）に合わせて、自動で配色が切り替わります

## 研修での流れ

1. 講師が `qr.html` をプロジェクターに映すか、`qr.png` をスライドに貼り、参加者に読み取ってもらう
2. **STEP 1 点数を選ぶ**：8つの領域の「いまの点数」を選ぶ → そろったら「理想の点数」を選ぶ
3. **STEP 2 人生の輪を見る**：いま（塗りつぶし）と理想（点線）が重なった輪と、ひとことまとめを見る
4. **STEP 3 振り返る**：気づいたこと・いちばん変えたい領域・最初の一歩を書く（必要に応じて問いカードで深める）
5. **STEP 4 画像で保存する**：輪・まとめ・振り返りを1枚の画像にして、端末に保存する

## 主な機能

| 機能 | 内容 |
| --- | --- |
| いまと理想の点数 | 「いまの点数」「理想の点数」を切り替えて、それぞれ1〜10点で選びます。切り替えボタンは、スクロールしても画面の上に残ります。理想を選ぶときは、数字の下に「いま」の印が出ます |
| 人生の輪 | いまの点数を塗りつぶし、理想の点数を点線で重ねて描きます。各領域の横に「いま → 理想」の点数を表示します |
| ひとことまとめ | いちばん高い領域・いちばん低い領域・理想との差がいちばん大きい領域を、自動で表示します（同じ点数の領域が複数あるときは、すべて表示） |
| 振り返り | 「気づいたこと・感じたこと」「いちばん変えたい領域」「最初の一歩」を書けます（各200字まで）。書いた内容は保存する画像にも入ります |
| 問いカードへのボタン | 「いちばん変えたい領域」を選ぶと、その領域の[問いカード](https://coaching-l.github.io/reflection-cards/)を別のタブで開けます（`?cat=` でカテゴリを指定） |
| 自動保存 | 入力した内容は、その端末のブラウザに自動で保存されます。研修中に別のアプリを開いて戻ったり、画面を閉じたりしても消えません |
| 領域の説明 | 各領域の名前の横の「?」で、その領域に含まれるものの短い説明を開けます |
| 画像をダウンロード | いまの点数がそろうと押せるようになります（理想の点数と振り返りは任意） |
| 最初からやり直す | 入力した内容と、端末に保存した内容をすべて消します |

### 画像の保存のしかた（端末ごとの動き）

- **iPhone・iPad**：共有メニューが開くので、「画像を保存」を選ぶと写真アプリに保存されます
- **Android・PC**：画像ファイル（`人生の輪_お名前_20261007.png` の形式）がダウンロードされます
- **LINE・Instagram などのアプリの中のブラウザ**：ダウンロードできないことが多いため、画像を画面に表示して、長押しで保存してもらいます
- QR コードの URL の末尾には `?openExternalBrowser=1` を付けています。LINE の QR コードリーダーで読み取っても、LINE の中ではなく、ふだんのブラウザ（Safari・Chrome）で開くようにするためです

### 端末への保存について

- 保存先は、その端末・そのブラウザの中（`localStorage`）だけです。講師や他の参加者には届きません
- 同じ端末でも、別のブラウザ（Safari と Chrome など）では引き継がれません
- プライベートブラウズ（シークレットモード）では、閉じると消えます
- 研修会場の共有の端末で使ったときは、最後に「最初からやり直す」で消してください（画面にも案内を出しています）

## ブログ（WordPress）版との違い

| | ブログ版 | このアプリ（研修用） |
| --- | --- | --- |
| 結果の送信 | あり（Google Apps Script 経由でメール） | **なし**（端末の中だけ） |
| お名前 | 必須 | 任意（画像とファイル名に入る） |
| 点数 | いまの点数 | いまの点数＋理想の点数 |
| ひとことまとめ・振り返り・問いカード連携・自動保存・領域の説明 | なし | あり |
| 見た目 | ブログに合わせた配色 | 問いカード・ポモドーロタイマーと同じ COACHING-L の配色（ダークモード対応） |

8つの領域の名前・順番・色、輪のグラフの描き方は、ブログ版と同じです。

## デザイン

- 配色・ロゴ・ファビコンは、COACHING-L の問いカード（coaching-l/reflection-cards）・ポモドーロタイマー（coaching-l/pomodoro）とそろえています
  - ライト：背景 #f7f8fa、紺 #042143、金 #c09e5c
  - ダーク：背景 #02172f、ボタンや選んだ項目は金 #c09e5c
- 8つの領域の色は、ブログの「人生の輪」ツール・問いカードと同じです
- 保存する画像は、画面がダークモードでも、いつも白地の明るい配色で作ります

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面の骨組み |
| `style.css` | デザイン（色・レイアウト） |
| `app.js` | 動き（点数・輪のグラフ・まとめ・自動保存・画像の作成とダウンロード）と、8つの領域の設定 |
| `qr.html` | 研修でプロジェクターに映す、参加者用の QR コードの画面 |
| `qr.png` | 参加者用の QR コード画像（スライドに貼る用） |
| `icons/` | ロゴとファビコン（問いカード・ポモドーロタイマーと同じ画像） |

`style.css` や `app.js` を変えたときは、`index.html` の中の `style.css?v=1`・`app.js?v=1` の数字を1つ上げてください。ブラウザに古いファイルが残って、表示が崩れるのを防ぐためです。

## 領域の名前・説明を変える方法

`app.js` の先頭にある `SETTINGS` の中を書き換えます。

```js
{
  name: "自己成長",           // 名前
  note: "学びや自己啓発など",  // 補足（画面では小さく表示。不要なら ""）
  cat: "growth",              // 問いカードの ?cat= に使うID
  color: "#BFAE45",           // 色
  desc: "新しい知識やスキルを学ぶこと、……" // 「?」で開く説明
}
```

- 並び順が、輪の真上から時計回りの順番になります
- 問いカードの公開URLを変えたときは、`SETTINGS` の `cardsUrl` も書き換えてください
- 領域の名前を変えると、参加者の端末に保存されていた前回の点数は使われなくなります（領域がずれて保存されるのを防ぐため）

## 公開URLと GitHub Pages の設定

GitHub Pages（main ブランチのルート）で公開します。

```
https://coaching-l.github.io/the-wheel-of-life/
```

QR コードの画面は `https://coaching-l.github.io/the-wheel-of-life/qr.html` です。

GitHub Pages の設定：リポジトリの **Settings → Pages → Build and deployment** で、Source を「Deploy from a branch」、Branch を `main` と `/ (root)` にしています。main に反映した内容は、数分でアプリにも反映されます。

> 無料プランで GitHub Pages を使うため、このリポジトリは問いカードと同じように「公開（Public）」にしています（個人情報や送信先は含まれていません）。

## QR コードを作り直す方法

公開URLが変わったとき（独自ドメインにした場合など）は、`qr.png` を作り直してください。
例：Python の [segno](https://pypi.org/project/segno/) を使う場合

```
pip install segno
python3 -c "import segno; segno.make('https://coaching-l.github.io/the-wheel-of-life/?openExternalBrowser=1', error='m').save('qr.png', scale=20, border=4, dark='#042143')"
```

`qr.html` の下に表示している URL の文字も、あわせて書き換えてください。

## 手元のパソコンで確認する方法

`index.html` をファイルとして直接開いても動きます。
ただし、ブラウザの制限で、保存する画像にロゴが入りません。公開時と同じ状態で確認したいときは、簡易サーバーを起動して `http://localhost:8000/` を開いてください。

```
python3 -m http.server 8000
```
